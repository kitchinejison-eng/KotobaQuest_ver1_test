ことばクエスト Ver2.5.7｜無料Qwen3-1.7B テスト版

【利用方法】
1. GitHub PagesにこのZIPをルートのまま配置する。
2. 日常会話・コミュニケーションの自由会話を開く。
3. 初期状態は「端末内のルール式会話」。追加ダウンロード不要。
4. 「生成AIを試す（無料）」を押すと、WebGPU対応を確認し、WebLLMとQwen3モデルを初回ダウンロード。
5. 読み込みが成功すると「Qwen3-1.7Bを利用できます。生成AIモードに変更しました。」と通知。
6. WebGPU非対応、容量不足、通信失敗、モデル読み込み失敗、推論失敗などは「生成AIが動作しないため、端末内のルール式会話に変更しました。」と通知し、従来のルール式で継続。
7. 「ルール式会話にする」ボタンでいつでも戻すことができる。

【費用】
WebLLMとQwen3モデルは無償。外部の有料API・AIサーバーを使用しない。通常の通信・電気代は別。

【必要条件・制限】
- モデル: Qwen3-1.7B-q4f16_1-MLC。公式WebLLMカタログの推定VRAM 2.0GB。
- 実行: PC Chrome / Edge等のWebGPU対応ブラウザをまず推奨。スマホは対応端末で個別検証。
- 初回のWebLLMライブラリとモデル（1GB超）にはインターネット接続と保存領域が必要。
- model weights とWebLLMの第三者コードはZIPには未収録。CDN: https://esm.run/@mlc-ai/web-llm@0.2.89 。WebLLMのモデルデータ配信元はライブラリ側の公式設定に従う。
- ブラウザのキャッシュ削除や容量不足で再取得が必要。オフライン再起動は端末とキャッシュ条件に依存するため未保証。
- file:// で直接開く場合はWebGPU/ServiceWorkerに制限がある。HTTPSまたは localhost でテストする。
- 端末へは文字会話を送信せず、ローカルで推論する想定。ただし外部CDNからライブラリとモデルを取得する。
- この環境から外部CDNへ接続できないため、モデルの実ダウンロード・実際の文章生成は未検証。統合コードと構文・モックテストまで。
- 医療的な診断や評価には使わないこと。入力内容に個人情報は含めない。
