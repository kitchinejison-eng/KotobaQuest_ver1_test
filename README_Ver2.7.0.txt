ことばクエスト Ver2.7.0 PC版
更新日：2026-11-25

Windows：ZIPを展開して START_PC.bat を実行（localhost推奨）。Mac：展開先をローカルHTTPサーバーまたはHTTPSで開く。START_HERE.html から直接利用も可能だが、マイクなどは制限される場合あり。

既存の学習・ゲーム・音声・問題データ、メーカーの現行ファイル、ライセンスを維持。
過去のメーカー復元バックアップ、開発テスト、旧版変更履歴、問題管理用Python/CSV等を配布物から除外。
元ZIPは編集・復元用として保管推奨。
同一公開URLで更新すれば従来のブラウザ保存データを継続利用できる設計。別URL/別端末ではデータは自動移行しない。
Qwenモデル本体は元ZIPにも同梱されていない。AI・マイク・読み上げ・3Dは対応端末とブラウザに依存。
